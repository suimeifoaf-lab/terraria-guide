召喚職の強くなり方

ミニオン・ムチ・セントリーで戦う人のための順路 ・ マスター / 3人 / 堕落 / Terraria 1.4.5.8

召喚職は 1.4 で「ミニオンを出して眺める職」から「自分でムチを振ってミニオンに指示する職」に変わり、1.4.5 でマナが不要になり、1.4.5.7 でタグ系アクセが一気に増えました。このページは wiki の Guide:Class setups(2026-10 時点)を骨格に、各アイテムの数値を wiki で確かめ、Steam の議論や日本語ブログの推奨を照らし合わせて書いています。全体の流れは「3人旅の手引き」、集めるべきアクセは「アクセとミニオン」へ。アイテム名をクリックすると wiki が開きます。

仕組みボス前EoC〜Skeletron地底〜WoFHM序盤メカ〜PlanteraPlantera後終盤堕落ワールド3人での動き誤解

0先に覚える仕組み

ミニオン枠
初期 1。防具(Flinx Fur Coat +1 / Bee +2 / Obsidian +1 / Spider +3 / Forbidden +2 / Hallowed Hood +3 / Chlorophyte Visor +3 / Tiki +4 / Spooky +4 / Stardust +5)、アクセ(Pygmy Necklace・Necromantic Scroll・Papyrus Scarab 各 +1)、Summoning Potion +1、Bewitching Table +1。全部で最大 11。Optic Staff は2体で1枠、Abigail / Desert Tiger / Stardust Dragon は「枠を注ぐほど1体が強くなる」型
タグ
ムチで叩いた敵に 4 秒の印が付き、ミニオンとセントリーの攻撃に「タグダメージ」が固定値で加算される。手数の多いミニオン(Blade Staff・Spider)ほどタグの価値が高い。1.4.4 からセントリーにも乗る
タグ枠(1.4.5.7)
同時に乗せられるムチの種類は初期 1。Silver Bracer / Silver Shield / Wicked Armlet / Wicked Claws / Armlet Of Ruin / Mobius Strip / Ouroboros Ring が +1、Twilight Grasp が +2(同じ系統は重複しない)。実用上の最大は Twilight Grasp + Ouroboros Ring の 4。上限を超えると古いタグから消える。複数ムチの重ね掛け(ムチスタック)はこのアクセがあるときだけ成立する
ムチの速度
近接速度のアクセ(Feral Claws 系・Berserker's Glove・Wicked Claws 各 +12%)とムチ固有のバフ(Snapthorn 12% / Durendal 25% / Dark Harvest 35%)で速くなる。Obsidian armor のセット効果 15% は別枠で掛け算
多段ペナルティ
1振りで2体目以降に当たると威力が下がる。Leather 50% / Snapthorn・Soulscourge 40% / Firecracker 34% / Cool Whip・Starcrash 30% / Durendal・Kaleidoscope 20% / Spinal Tap・Dark Harvest・Constellation 10% / Morning Star・Possession 5%。雑魚戦の体感差はここ
セントリー枠
初期 1。Old One's Army のアクセ +1(同系統は1つだけ)、Squire / Monk / Apprentice / Huntress 防具 +2、Valhalla Knight など上位 +3、Stardust +1。1.4.5.7 から Heavy Sling 系でセントリーを持ち運べる
特殊効果のムチ
Starcrash(隕石 = ミニオン1ヒットの 1.33 倍)、Firecracker(次の一撃が 2.75 倍で爆発)、Vulgar Display of Flower(花弁 2.25 倍)は「基礎ダメージが高い少数のミニオン」向け。固定タグのムチ(Spinal Tap・Snapthorn・Kaleidoscope)は「手数の多いミニオン」向け。この2系統を混ぜないのがコツ
マスターでの考え方召喚職は防具の防御が全職で最低。wiki も各段階で「防御型(Titanium Mask・Squire・Valhalla Knight)との混成」を併記している。3人マスターではHallowed Hood(被弾1回無効)を基準に、火力防具は余裕が出てから。アクセのリフォージは Warding。

8堕落ワールド(病み村)での固有事情

  • 序盤ムチは Soulscourge(Demonite Bar 12)。Crimson 側の Vasculash より 2 低いぶん射程が 1 長い
  • Obsidian armor と Mushroom Staff の Shadow Scale は EoW の胴 27 節ぶんで足りる
  • Wicked Armlet は Cursed Hammer(ハードモードの堕落)1/25。Crimson Axe を待つ必要がないので、Twilight Grasp がメカ前に組める
  • Corrupt Mimic の Putrid Scent(20%)は、Shimmer で Flesh Knuckles(盾役向け)に変えるより、召喚職なら Scout's Sling(Heavy Sling + Putrid Scent。ダメージ +5%・狙われにくい)の素材にする方が合う
  • Flask は Cursed Flames。Ichor は Crimson 産なので Flask of Ichor は使えない(Shimmer でも Cursed Flame ↔ Ichor は変換可)

93人で遊ぶときの召喚職

  • 手が空くのが最大の強み。ミニオンが殴っている間に、落ちたお金を拾う・Nurse まで走る・Heart Statue のスイッチを押す、を引き受ける
  • Berserker's Glove はムチにもオートスイングと速度 +12% が乗るが、敵の狙いを集める(+400)。防御の低い召喚職が付けると自分が狙われる。3人のうち盾役が付け、召喚職は Wicked Claws で速度を取る
  • 逆に Scout's Sling / Putrid Scent は狙われにくくなる(−400)。召喚職の「見えない盾」
  • Heavy Sling で持ち運べるのは自分のセントリーだけ。他人の砲台は拾えない
  • Stardust Guardian は囮にならない(1.4.0 で攻撃役に変更)。囮が欲しいときは盾役の Hero Shield / Flesh Knuckles に任せる

10情報源で食い違う点・古い情報

  • 「1.4.5 でムチの重ね掛けは廃止」: 2026 年前半の日本語・英語記事の多くはこう書くが、1.4.5.7(2026-08)でタグ枠アクセがあるときだけ復活した。1.4.5.7 未反映の記事に注意
  • Electric Eel のドロップ率「1/6」は旧値。1.4.5.7 から 1/7
  • Dark Harvest の威力は wiki の 110 が正(まとめサイトに別の数字がある)
  • Firecracker の「タグ 0」は仕様どおり。接頭語の分だけが乗る
  • Foxparks を「セントリー」と呼ぶ記事があるが、wiki ではミニオン扱い。枠を 1 つ使うことは病み村でゲーム内のミニオン数を見て確認した(2026-10-17)
  • Steam に投稿された 1.4.5 向けの召喚ガイド2本は削除済みで中身を確認できなかった。このページの根拠は wiki と Steam 掲示板の議論、日本語ブログ(1.4.5.0 時点)まで
