集めるべきアクセサリーとミニオン

クラスを問わず「持っていると楽になる」もの ・ マスター / 3人 / 堕落 / Terraria 1.4.5.8

マスターはアクセ枠が 6、Demon Heart で 7。枠の価値が高いので「誰が持っても強いもの」から集め、残りをその日のクラスで差し替えるのが3人旅の形です。このページは wiki の各アイテムページと Guide:Class setups、Modifiers を一次情報に、英語・日本語の攻略記事(2026 年)を照らし合わせています。合成の系統図は「手引きのアクセサリータブ」、クラス別の順路は「魔法職」「召喚職」へ。アイテム名をクリックすると wiki が開きます。

前提移動生存便利クラス別永続強化相棒・乗り物リフォージ7枠の例未確認

0前提: マスターと3人で変わること

  • Treasure Bag は攻撃した全員に1つずつ出る。Shield of Cthulhu・Worm Scarf・Demon Heart・Soaring Insignia など Bag 確定品は、取り合いにならず3人分そろう
  • Demon Heart は1人1回、自分の Bag から取る。クラシックのワールドに持ち込むと 6・7 枠目は無効
  • マスターのボスは Relic(置物)確定、ペット・光ペット・マウントの召喚アイテムを 25%(攻撃した各人が別々に抽選)。Eye of Cthulhu は 0x33's Aviators 確定
  • 防御がダメージを 100% 減らす。だから防御系アクセとリフォージの Warding の価値が Expert より高い
  • 同じアクセは2個付けられず、素材違いの同系統も片方しか効かない(Charm of Myths と Catalyst Band、Star Veil と Cross Necklace、Celestial Shell と Celestial Stone など)。例外は明記する

4クラス別の「火力枠」の系統

その日のクラスで差し替える枠。合成の系統図は手引きのアクセサリータブに。

  • 全クラス共通: Avenger Emblem(クラス Emblem + 各 Soul 5)→ Destroyer Emblem(+ Eye of the Golem)。ただし召喚職は Destroyer Emblem にしない(ミニオンはクリティカルしないので Avenger のまま)
  • 近接: Feral Claws → Warrior Emblem / Berserker's Glove → Mechanical Glove → Fire Gauntlet。ヨーヨーは Yoyo Bag → Magic Yoyo Bag(1.4.5)。Pyroclastic Stone(Snapping Stone + Magma Stone)は近接・遠距離どちらにも
  • 遠距離: Poison Barb / Harpy Charm / Snapping Stone(序盤)→ Ranger Emblem / Magic Quiver(Skeleton Archer 2.5%)→ Molten Quiver(+ Magma Stone)/ Stalker's Quiver(+ Putrid Scent、狙われにくい)→ Phoenix Quiver(Harpy Charm + Molten Quiver)/ Chaos Cylinder(Hallowed Mimic 20%)。Recon Scope と Sniper Scope は重複して合計 +20% / +20%。矢筒は2つ持っても矢のダメージ分しか重ならない
  • 魔法: Celestial Cuffs / Magnet Flower / Mana Regeneration Band → Restoration Shield → Sorcerer Emblem → Celestial Emblem / Mana Cloak / Mystic Arts Sash / Arcane Flower。詳しくは「魔法職の強くなり方」
  • 召喚: Pygmy Necklace / Feral Claws → Silver Bracer → Summoner Emblem / Twilight Grasp / Wicked Claws → Hercules Beetle + Necromantic Scroll → Papyrus Scarab / Ouroboros Ring。セントリーは Heavy Sling 系。詳しくは「召喚職の強くなり方」

7リフォージ(接頭語)の決めごと

  • wiki(Modifiers): Warding(防御 +4)がほとんどの場面で最良。ハードモード前と高防御ビルドで特に効き、マスターは防御が 100% 効くので Expert より価値が高い
  • Menacing(ダメージ +4%)/ Lucky(クリ +4%)は「死なない前提で火力が勝負を決める」とき。Duke Fishron や昼の Empress のような一撃が大きい相手では Warding の価値が落ちる
  • 召喚職と基礎ダメージの低い武器は Menacing が合う(ミニオンはクリティカルしないので Lucky は無意味)
  • 英語の攻略記事(2026 年 9〜10 月)は「火力アクセは Menacing、生存アクセは Warding」「マスターはボスを覚えるまで Warding」で一致
  • このチームの決めごと: 盾役は Warding、火力役は Menacing / Lucky、初見のボスは全員 Warding。6〜7 枠で防御 +24〜28 の差は、マスターでは「序盤の一発」をそのまま 1 回ぶん減らす
